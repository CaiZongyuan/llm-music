# Triage labels

用户确认使用默认标签。

| 技能角色 | GitHub 标签 | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 待维护者评估 |
| needs-info | needs-info | 待补充信息 |
| ready-for-agent | ready-for-agent | 规格明确，可在阻塞条件满足后领取 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不实施 |

执行阶段以原生阻塞关系、阶段验收与 owner 为准；分流标签不替代它们。
