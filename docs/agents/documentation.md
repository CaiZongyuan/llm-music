# 文档维护规范

创建或修改公开文档、导航、教程示例、API 参考及站点生成流程时，遵循本文。文档站使用 Astro + Starlight，发布到 GitHub Pages。

## 内容与教学

- 主教程面向音乐创作者，按使用方法与玩法组织入口：做出第一段音乐、从参考音频转谱、调整风格/歌词/seed 并选择版本。环境准备、Doctor、API、架构和开发资料作为按需查阅的次级指南。
- 教程用同一个音乐 Project 延续创作目标、素材、输入与试听笔记。每章说明输入选择、当前可用操作、结果检查、一次失败恢复和下一种玩法；生成结果先为 Candidate，创作者明确保存后才成为 Version。编辑、Cover 与内置比较操作随已实现阶段加入。
- 随已实现阶段推进教程；清楚标示计划与隔离预览。公开页面描述当前行为，工单过程与验证日志保留在维护记录中。
- 概念先给简短定义、关系图和最小例子；操作先让读者得到结果，再解释原因。保持清晰导航、克制排版和明确的下一步。

| 页面类型 | 必须包含 |
| --- | --- |
| 概览 | 当前范围、读者任务、入口与首个结果 |
| 教程 | 起始素材/Project/创作目标、输入选择、完整操作、结果位置与试听判断、一次失败恢复、下一种玩法；需要 CLI 时将完整受控代码放在补充说明 |
| 指南 | 目标、前提、最小完整操作、验证与恢复；可以独立进入 |
| 概念 | 定义、实际关系图、最小例子、取舍与失败边界、实践入口 |
| 参考 | 事实来源、分类索引、参数、返回、错误、限制与用法链接 |

采用 ASD-STE100-inspired 的简明技术语言：短句、主动语态、一步一个动作、稳定术语。条件放在相关动作前，结果紧跟动作；命令、字段、单位和界面标签保持准确。中英文保留相同的前提、行为与失败边界。

## 来源与生成

建站时实现以下生成流程：章节清单、正文、源码示例、OpenAPI 与配置元数据 → 生成 Starlight 内容和导航 → 静态构建 → 检查产物 → 发布。

- `docs/` 中的 Markdown / MDX 是正文唯一来源；`docs/site.json` 登记公开章节的稳定 id、类型、分组、语言标题、正文路径与发布路径。只发布登记的页面，维护规范、规划与预览按用途保留。
- 中文正文旁维护对应 `.en.md` / `.en.mdx`，用同一章节 id 关联语言版本。新增公开章节成对交付；既有缺译页登记负责人和待补状态，语言切换指向实际存在的页面。
- 连续教程用章节 id 显式声明 `previous` / `next`，未声明时关闭自动串联。侧栏、语言对应关系与前后章链接都从同一清单生成；已发布路径变更时维护旧链接。
- `apps/docs/` 承载 Astro 配置与组件；`apps/docs/src/content/docs/` 承载生成页面。生成目录、缓存与 `dist/` 留在 Git 外，每次开发启动与构建前重新生成。
- 教学示例使用受版本控制的完整代码；正文以 `<<< 相对源码路径` 引用。生成器读取并转换成代码块，核对文件存在且位于仓库内，避免维护第二份代码。
- 正文中的仓库相对链接由生成器解析：已登记文档转为同语言站内链接，源码转为对应提交的 GitHub 链接。页面显示源码版本与正文来源。
- API 参考与前端客户端共用 FastAPI / Pydantic 导出的 OpenAPI；配置参考从真实 Settings 元数据生成。保留字段、默认值、错误码与限制的唯一来源，生成过程无需加载模型或连接 GPU Runtime。
- 图片与截图保存在 `apps/docs/public/`；截图记录版本与数据是否模拟。复用产品已有设计 token 和真实组件，新增生成来源须有实际文档需求。

## 更新与验证

1. 核对当前公开接口、源码和行为检查，确定读者任务与页面类型。
2. 同批更新功能、教学代码、中英文正文、章节清单和生成参考；注明执行目录、依赖、占位值及持久数据影响。
3. 运行受影响的示例与行为检查，再检查生成来源、导航、链接和静态构建。
4. 在浏览器核对章节导航、语言切换、搜索、主题及 GitHub Pages 子路径；可见变化对照已确认预览。
5. 主分支通过 CI 后发布该提交已验证的构建产物，核对线上地址、页面与源码版本。

建站需提供以下根目录入口；命令由实际实现落实：

| 入口 | 行为 |
| --- | --- |
| `pnpm docs:dev` | 生成页面与参考，启动 Astro 文档站 |
| `pnpm docs:check` | 核对章节与路径唯一性、来源、源码引用、语言配对、导航关系及生成参考一致性 |
| `pnpm docs:build` | 重新生成、执行 Astro 构建，并检查最终 HTML 的内部链接、锚点、资源与部署 base |

完成条件：读者可以在声明版本中完成任务，示例与接口一致，中英文语义对应，生成及产物检查通过，实际验证范围有记录。源码版本标识只表示构建来源，不能代替操作验证。
