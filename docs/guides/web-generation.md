# 在工作区生成、试听并留下版本

沿用“雨后的散步”项目。先尝试一段温暖的钢琴歌曲，检查人声、旋律与乐谱，再保存喜欢的结果。正式 Web 通过应用服务读取和保存数据；CPU FakeRuntime 只返回已标明的测试音调与示例乐谱。

## 从一个清楚方向开始 {#generate}

1. 在项目工作区打开“音乐生成”。填写“音乐风格”，例如“温暖的钢琴，轻快的旋律，清楚的中文人声”。
2. 在“歌词”写一小段内容，可以用 `[Verse]` 和 `[Chorus]` 组织段落。保留随机种子 `2026192201`，方便记录这次尝试。
3. 确认“可以开始创作”，再选择“生成一段音乐”。当前片段长度固定为35秒；种子须为0到9007199254740991之间的整数。
4. 在“创作任务”查看阶段。未知进度只显示阶段，不推测百分比。任务完成后，结果成为可试听的 Candidate，还没有保存为 Version。

如果模型或运行资源没有准备好，提交按钮禁用。恢复资源后选择“重新检查准备状态”。界面语言与主题切换保留当前输入。

## 试听、看谱与调整 {#listen}

1. 选择“试听这段音乐”，等待底部播放器读取音频，再选择“播放”。
2. 留意旋律是否清楚、人声是否符合歌词、开头与结束是否完整。底部播放位置可以拖动，也可以用键盘调整。
3. 展开“试听片段”，填写音频范围内的起点和终点，选择“设置片段”，再选择“播放片段”。播放到终点会暂停；片段须满足 `0 ≤ 起点 < 终点 ≤ 音频时长`。也可以拖动波形上的片段边界。
4. 选择“查看乐谱”检查这次生成的 Score；切换“歌词与输入”或“版本”时，持续播放器继续播放同一音频。生成 Score 使用自己的 ABC；没有转谱参考音频或 MIDI 时，页面明确显示这些结果不可用。

“歌词与输入”显示当前草稿。“提交时的输入”显示 Candidate 的保存快照。选择“用这次输入继续探索”可把快照复制回草稿；不会改写原来的 Candidate 或 Version。先保持歌词和种子，只改变风格，再生成另一候选，比较你的试听笔记。

想让新歌曲使用明确修改的旋律时，按[编辑与重新生成教程](../learn/edit-score.md#regenerate)检查、试听并保存选定 Score，再使用乐谱页中的“从选定 Score 生成”。这次任务保留实际 ABC、来源 Score 与父版本；直接从风格和歌词生成仍是另一种创作操作。

## 明确保存喜欢的结果 {#save}

1. 试听后，在候选区域填写“版本名称”，例如“雨后的散步 · 温暖钢琴”。
2. 选择“保存为版本”。成功后出现“查看已存版本”，版本列表增加这一次选择。
3. 打开版本查看原输入与结果。刷新页面仍读取同一 Version 标识和音频；后续生成不会覆盖旧版本。

“版本”显示同一 Project 的已保存父子关系，允许多个没有父版本的起点。每份记录的父版本链接、输入、来源与“已保存输出”来自保存快照。要从较早版本派生，选择“从此版本继续创作”，再明确选定其乐谱并从 Score 生成；需要复制原风格、歌词和 seed 时，另选“使用此版本输入”。仅检查或进入版本不会替换现有草稿，也不会创建 Job。新结果先为 Candidate，命名并明确保存后才增加一条子版本关系。

候选列表由应用服务保存，刷新后可以重新选择。未保存 Candidate 不属于版本历史。当前草稿只在打开的 Web 中保留；刷新后可以从任务链接恢复提交输入，或从候选选择“用这次输入继续探索”。普通素材与草稿 MIDI 的试听选择只属于当前 Web 会话；A/B 选择可按下节恢复，播放位置不保留。

## 比较两份已保存作品 {#compare}

1. 在“版本”的“选择两份已保存版本”中选择不同的“版本 A”和“版本 B”，再选择“使用这对版本”。没有第二份时选“只试听 A”；Candidate 须明确保存后才能加入比较。
2. 等待读取，选择“播放”，再用“切换到 A”或“切换到 B”回听。切换保留绝对秒数，不按长度比例换算，也不对齐拍点；暂停时切换保持暂停，播放时等目标就绪后继续。
3. 展开“共同试听片段”，设置两份音频都包含的起止时间，选择“播放片段”。它只播放一次，到终点暂停。手动 seek 会取消这次限界；波形片段可以拖动与调整边界。
4. 打开乐谱、歌词与输入或设置，持续播放器保留同一音频。明确试听其他素材或草稿 MIDI 才换源；选择“返回比较”从0秒暂停重新进入 A/B。

较短目标无法到达当前秒数时，停在真实末端并暂停；返回较长音频也不会自动开播。自然结束后明确“播放”从头重听。更换比较对从0秒暂停，旧片段不适合新共同范围时按提示重设。

在同一 Project 中刷新，只恢复仍有效的版本 id 与 A/B 侧，从0秒暂停，不恢复片段。选择失效时重新选已保存版本；存储不可用仍能本次试听，刷新恢复不保证。音频或版本读失败先重新读取；缺原 Audio/ABC 时恢复原文件，不会删除既有历史或自动生成音乐。更多玩法见[版本变化教程](../learn/variations.md#compare)。

## 失败后继续这次尝试 {#recover}

- 显存不足、缺模型、流程失败或已取消：原风格、歌词与种子保留。恢复资源后，明确选择“创建新的重试任务”，或调整输入后重新生成。重试创建新的 Job，原任务及已有版本保留。
- 音频无法播放：选择“重新读取音频”，从0秒暂停恢复。仍然失败时，从项目素材下载原文件检查；候选与输入保留。
- 版本保存失败或确认中断：名称与候选保留。先选择“重新读取已保存版本”，检查是否已经保存；需要恢复时选择“再次保存同一版本”。它使用首次点击的名称与候选，后续文本修改不会改变恢复意图。相同候选与相同名称的重复保存返回同一 Version，不增加重复历史。
- 读取候选或版本失败：使用相应“重新读取”动作。错误不会显示为空历史。

单一持续播放器支持素材试听、已保存版本 A/B、seek和有界片段。乐谱页支持 ABC 编辑、MIDI 试听导出与从选定乐谱重新生成；已保存版本可查看关系并明确继续创作，Cover 支持两种模式。长曲生成仍属于后续阶段。启动正式 Web 与独立应用服务的方法见[工作区指南](web-workspace.md#launch)。
