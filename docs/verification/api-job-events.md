## Source and ownership facts

Read-only pinned source: Comfy `protocol.py` defines TEXT=3; `server.py:1545` encodes node-length/node/caption and `encode_bytes` adds the event header. Plugin `NodeProgress.text` broadcasts without prompt identity. Owned attempt-specific executing context plus current target-running HTTP confirmation is required before attribution. Any ownership switch, invalid source, terminal hint or disconnect loses context. Raw prompt/node/caption/errors stay behind the adapter.

Plugin `generate.py:Stages` explicitly states its weighted shares are not measurements. Generate and SheetSage token/node bars therefore supply no reliable whole-Job ratio. Pinned caption prefixes provide phase evidence. The native queue alone provides running, not transcribing. A fixed phase index was rejected: operation whitelist and sticky saving/terminal states are required, while legitimate sourced loading can recur. No intermediate G35 reload was claimed without a source trace.

The shared Job owner alone mutates persistent lifecycle state and imports results. Subscription callbacks only enqueue existing typed RuntimeStatus observations; non-running hints cannot themselves import or complete. `on_change` reads a fresh committed Job, and observer failure cannot change its result. One broker retains only active subscriber streams, bounds each buffer, checks source time/terminal stability, and sends a fresh durable snapshot before accepting buffered updates. Reconnect is snapshot recovery, without a persistent event-log/cursor promise. Subscription close belongs to the worker's finally; public disconnect only removes its scoped listener.
