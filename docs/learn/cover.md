继续 Morning song Project。把已有版本的开头，或自己的 16 秒参考片段，带到一种新风格中。先检查乐谱，再决定生成什么；结果仍由你选择是否保存。

## 1. 选一段参考，而不是整首歌 {#reference}

打开项目的“改编”。可以选择已有 Reference Audio，也可以选择一个有音频的已保存 Version，把它的**开头 16 秒**保存为新的参考。应用从该 Version 的真实音频文件提取 PCM16、48 kHz、双声道 WAV；原音频不改变。参考记录保留 source Version、source Audio Asset、起点、帧数和原文件 hash。

本地上传继续使用恰好16秒 PCM16 WAV：24 kHz单声道或48 kHz双声道。上传的参考没有来源父版本。不能仅给上传文件附加一个版本名称来冒充来源，也不能把35秒生成音频原样当作支持的转谱输入。

先试听参考，记下一处容易听清的音高或节奏。这是稍后检查转谱的依据。

## 2. 转谱，保留一个可检查的中间成果 {#inspect}

检查转谱准备状态，提交一次 Transcribe。完成后，中间 Score 的 ABC、谱面与 MIDI 都可查看；它仍关联原 Reference。版本参考的转谱 Score 保留真实 source Version 作为 parent，后续保存编辑继续继承它。

在同一页面检查旋律和节奏。转谱不会识别歌词，也不保证每个音符准确。Vocal 可以全是休止，Ins 可以有音符；melody 模式会保留这两条谱线，不会自动把器乐线变成人声线。

## 3. 修改、保存原谱，再选定 melody 的有效输入 {#select}

1. 在 ABC 中只改一个乐句，更新谱面并试听草稿 MIDI。无效文本会保留，旧谱面标明过期。
2. 保存并选定这份 Score。保存乐谱创建新的不可覆盖 Score/Asset，不创建推理任务或 Version。
3. 检查 melody 的有效 ABC，再明确选定该输入。它去掉音乐行中的和弦符号，保留 Vocal/Ins 音符、节奏、节拍、速度及声部名称。原谱仍保存；有效输入可以单独试听。
4. 更换参考、转谱出另一份 Score，或继续改稿后，重新检查和选定。即使两份 ABC 文本相同，也必须核对真正的来源。

新风格引导伴奏。melody 描述的是提交的音乐提示与生成指令，不能保证原录音的音色、人声身份或逐音一致。**full Cover 在后续阶段交付**；本次不能选它代替缺失的 melody 能力。原有 GenerateFromScore 仍使用其既有 full 配置。

## 4. 只换风格，听一次新的演绎 {#generate}

保留 Morning song 的歌词和 seed，只把风格换成轻柔钢琴或清晰的民谣吉他。检查 melody 准备状态，再明确生成。转谱与生成是两个独立 Job，中间有你的检查步骤。

提交会冻结 Reference、转谱来源、保存编辑、original/effective ABC、mode、style、lyrics 和设置。等待时可以继续写草稿；新修改不会进入旧 Job。结果先是 Candidate，用持续播放器试听旋律、节奏、伴奏和结尾。切到歌词或版本，播放器继续。

满意后命名并保存 Version。版本参考使用真实 source Version 的 parent；上传参考没有 parent。查看新版本的实际输入与来源链，再打开旧版本，确认它的乐谱和音频仍在。完成任务本身不会增加版本历史。

## 失败后，从保留的乐谱继续 {#recover}

- 转谱失败或取消：参考、已有中间 Score 和保存编辑保留。先检查当前 Job，再明确重试转谱。
- 模式或模型不可用：先恢复准备状态并重新检查。应用不会换成 full 或普通 Generate；有效乐谱仍可使用。
- 生成 OOM、失败或取消：保留中间成果与原任务。确认终态后，用同一冻结输入创建新的重试 Job，无需重新转谱。
- 提交回执不明：先读取项目任务并检查实际输入，不自动重复生成。刷新后读取服务端的原记录；未保存草稿需要从已保存 Score 重新开始。
- 参考或版本保存回执不明：读回同一保存 id/结果，再明确恢复同一意图。后来改的来源或名称不会悄悄改变这次恢复。

## 下一种玩法：保留乐句，只研究伴奏 {#ideas}

用同一选定乐谱、歌词和 seed，分别尝试“轻柔钢琴”和“稀疏木吉他”。每次先试听 Candidate，记下节奏密度、旋律清晰度及结尾，再保留值得研究的版本。当前按35秒配置创作；这不证明长曲或任意原录音的质量。

需要脚本时再查阅[Cover API 指南](../guides/cover-api.md)。模式来自[锁定插件](https://github.com/pytraveler/YuE2-ComfyUI/blob/fc78df9dfb214f396aa281f5b03519cefff5b00a/yue2_comfy/transcribe.py)，CPU 示例只验证操作与文件，不能代替真实 GPU 音乐结果。
