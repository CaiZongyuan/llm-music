## 一次只问一个创作问题 {#habit}

<p>例如：“同一首歌词，钢琴比木吉他更合适吗？”先保留原输入，改一个维度，再听人声、伴奏与结尾。每次生成得到 Candidate；只有你明确保存，它才成为 Version。</p><p>教程会带你选输入、看结果、恢复一次失败，再进入下一种玩法。想查参数或排障时，使用帮助与参考即可。</p>
