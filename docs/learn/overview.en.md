## Two things to know before starting {#entry}

<p>Open the local workbench and start by <a href="../guides/web-workspace.en.md">creating a Project</a>, then choose <a href="../guides/web-generation.en.md">generation and listening</a> or <a href="../guides/web-transcribe.en.md">Reference Audio transcription</a>. To control the next melody, follow <a href="./edit-score.en.md#regenerate">Score editing and regeneration</a> to inspect, audition, and explicitly select a Score. To try a new style from a reference, follow the <a href="./cover.en.md">Cover tutorial</a>, inspect the score, and choose melody or full. Save the results you like, then stay in the same Project to <a href="./variations.en.md#compare">compare two Versions and explore another direction</a>. Music generation needs a ready real Runtime; default fake mode produces a test tone. <a href="./resources.en.md">Preparation and entrypoints →</a></p><p>This site provides tutorials, copies inputs, and plays existing examples. Creation, uploads, saving, and comparison take place in the local workbench.</p>

## Ask one creative question at a time {#habit}

<p>For example: “Would piano suit the same lyrics better than guitar?” Keep the original inputs, change one dimension, then listen to the voice, accompaniment, and ending. Each generation creates a Candidate. It becomes a Version only when you explicitly save it.</p><p>Each tutorial helps you choose inputs, inspect results, recover from a failure, and try the next idea. Use help and reference when you need parameters or troubleshooting.</p>
