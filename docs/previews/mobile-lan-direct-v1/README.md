# 移动端地址直连预览

直接在浏览器打开 [index.html](index.html)。不需要启动 Expo、API 或静态服务器。

本次只调整连接入口，沿用已确认的黑色 Acid Hardware 色板和“声间”品牌。手机只输入一个电脑地址，点击“连接电脑”，成功后进入项目。页面右侧（小屏下方）的隔离工具可选择下一次连接成功、电脑不可达或电脑身份不符，以及项目正常、空、加载和失败状态。失败保留地址；连接中禁止重复操作；项目读取失败可以重读；演示项目只写本页内存。

与真实写入的隔离：无 fetch、WebSocket、存储、音频或业务 API；页面 CSP 禁止连接网络。输入的地址只是展示，不会访问。刷新页面即可清空演示。本预览不模拟 PIN、设备授权、配对撤销或模型证明倒计时。

依据是最新用户纠正；[确认与范围记录](../../ui/mobile-lan-direct.md) 说明其对旧配对预览的覆盖。历史预览保留。预览交付后可按该纠正继续正式实现，无需再次询问确认。

作者已在真实 Chromium 验证空输入禁用连接、成功连接与进入项目、连接中地址/提交禁用、不可达失败保留地址并重试成功、电脑身份不符和非法地址失败。项目空列表可新建演示项目；加载禁用新建；读取失败可重读。还检查返回连接和更换地址。桌面 `1280×1000` 与手机宽度 `390×844` 的截图保留在 [evidence](evidence/receipt.json)，并实际检查 loading 与移动 ready 的画面；浏览器无 JavaScript errors。Root 另独立打开预览并点击空输入、示例和连接中状态。

HTML 预览不能代替正式 Expo、API、GPU 或 APK 验收；正式变更的独立审阅与本预览作者验证分别记录。
