正式 Astro/Starlight 站使用六个成对的创作者章节：概览、第一段音乐、参考音频转谱、风格/歌词/seed 玩法、准备与排障、当前能力。旧的快速开始、Doctor、Runtime 转谱、架构四个章节保持原 path 与正文，在次级资料组可达；总计十个章节、二十个语言页面。

Markdown 正文是正式来源。歌词与配方从受版本控制的示例引用；第一章与三个变化的补充命令直接使用已验证、未修改的 `generate_save.py`。完整代码按需展开，正文围绕输入选择、试听判断与创作玩法。第一章配方和 MP3 保持原真实生成的对应关系，其他配方仍为未调试、未试听的建议。首页音频与只读配方脚本经部署 base 访问本地静态资源，页面没有业务 API 或 Runtime 请求。

2026-10-07，Developer 使用独立软件 Chromium `docs65-formal`，在 owned `127.0.0.1:18031` 的实际构建产物上验证十九个结果事实：四种配方及输入复制、现成 CLI 说明展开、前一章导航、同章节小节的语言切换、主题与刷新、原生键盘播放/暂停、静态索引加载与释放、MIDI 搜索跳转、空结果清空、真实搜索索引请求失败后的 Retry、旧技术 path、窄屏阅读与配方选择，以及静态 GET 隔离/无未捕获异常。主题、布局、主要创作入口与预览对照一致。

加载状态由浏览器验证器暂时延迟本地静态索引 fetch，释放后返回服务器的原始响应；失败状态只中断相同静态 URL。没有虚构业务响应，也没有提交生成或保存。截图、原始动作、校验结果与最终候选源码 pin 记录在 Root 的 `.scratch/p1-development/65-docs-usage/formal/`。MP3 在实际播放器中显示约 34.998667 秒；新推理与未试听配方效果没有被当作新增证据。

原生定位器对 Starlight 前一章链接的换行名称匹配失败，改用已读取 DOM 的 `rel=prev` 后成功。语言选择值实际是章节 URL，已按实读值操作。首次静态 transport barrier 清理了仍被 pending fetch 引用的测试属性，造成预期之外的索引失败；验证器改为捕获原 fetch 后通过，同一产品源码未因此修改。原失败均保留。

收尾按 reduce-complexity 删除了重复的 PowerShell 配方启动层，保持当前 CLI 为操作入口。其隔离 stub 检查曾挂起；经核对专属进程身份后停止，保留 harness/失败输出，无实际 uv/API/GPU 调用。最终代码没有这个启动层，验证范围聚焦实际保留的正文、配方、词句、音乐字节、站点来源与用户操作。Root 继续负责非作者 review、候选 CI、实际合并与后续发布记录。
