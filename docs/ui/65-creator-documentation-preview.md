## 最新用户纠正

用户在 2026-10-07 明确要求：**“教程方向应该为如何更好使用以及多样化玩法而不是开发”**。

本版因此以音乐创作者任务为主入口：第一段 35 秒音乐、参考音频转谱、调整风格/歌词/seed、试听与检查 Candidate、明确保存 Version。开发、源码、API、Doctor 和环境准备保留在帮助与参考，操作命令作为可展开补充。#29 的后续连续教程也应采用这个优先级。

用户此前已反馈真实音乐效果良好，并要求以后不为 Swagger UI 录屏。本预览不录屏；已有历史音乐只读复用，不运行新推理。

## 本版可审阅结果

六个中英文章节共用相同章节和小节 id。三份完整代表性教程延续 Morning song，给出输入选择、当前操作入口、下载位置、试听检查、一次失败恢复与下一种玩法。主按钮进入音乐与参考音频教程，玩法选择按钮只更新文档配方；参数与命令只能复制。

第一章复用 PR #58 实际输入与 561068 B MP3，风格、原创歌词和 seed `2026192201` 与收据一致。其他配方明确为未调试/未试听的灵感，未声称成功效果。生成只介绍已实现的 35 秒设置；转谱只介绍 16 秒 PCM16 mono24k / stereo48k。上传预算没有被写成推理能力。正式 Workbench Web、内置编辑、Cover、GenerateFromScore、A/B 和长曲均未作为当前可用功能。

预览自有静态服务使用 `127.0.0.1:18030`；不连接实际 API、共享 Runtime 或 GPU，不写入业务数据。
