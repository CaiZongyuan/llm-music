# Compressed PR verification media

`yue2-g35-validated-version.mp3` is a compressed listening copy of the earlier real YuE2 G35 application Version from PR #58. Its original FLAC was preserved during the later cancellation/retry validation. It is not a new generation from the browser test.

The source recordings and lossless audio remain unchanged. See `provenance.json` for hashes and scope. This evidence branch is independent of application source and is not a product release.
